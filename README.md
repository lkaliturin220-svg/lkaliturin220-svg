## 🖥️ Homelab

Всё крутится дома, на одной Proxmox-ноде:

| Сервис | Что делает |
|---|---|
| **Proxmox VE** | виртуализация: LXC-контейнеры + VM |
| **Pi-hole** | DNS-фильтрация рекламы |
| **NPMplus** | реверс-прокси + TLS для всех сервисов |
| **Mailcow** | собственная почта |
| **SearXNG** | приватный метапоисковик |
| **Matrix (Dendrite)** | свой мессенджер |
| **Immich** | фотоархив, свой «Google Photos» |
| **Minecraft** | Paper: Java + Bedrock (Geyser), голосовой чат |

Внешний вход — через Cloudflare, игровые порты — напрямую.
